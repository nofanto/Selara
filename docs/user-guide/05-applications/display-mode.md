# Display Mode

![](../../public/features/display-mode.png)

The **View** popover in the header — the same one that holds [Colour Modes](../06-display-settings/colour-modes.md) and [Grouping Modes](../06-display-settings/grouping-modes.md) — has a **Show** section controlling which layers the timeline draws. Use it to tailor the view to your audience or current task.

| Mode | What is shown |
|------|---------------|
| Both (default) | Initiative bars and the Deliverables swimlane together |
| Initiatives | Initiative bars only — the Deliverables swimlane is hidden |
| Deliverables | The Deliverables swimlane only — initiative bars are hidden |

## When to use each mode

- Use **Deliverables** when presenting the technology lifecycle to a stakeholder who does not need to see the initiative schedule. The view is cleaner and focuses attention on deliverable statuses and durations.
- Use **Initiatives** to reduce visual complexity when the deliverable layer is not relevant to the conversation.
- Leave it on **Both** for your day-to-day portfolio management work.

## Empty rows in Deliverables mode

In **Deliverables** mode, all asset rows are shown by default — even assets that have no deliverables configured yet. This lets you see the full shape of your portfolio and plan where lifecycle segments still need to be added.

If you want to hide assets that have no deliverables, set **Empty Rows** to **Hide** in the More Settings panel (the `···` button in the header). With that setting active, only assets with at least one lifecycle segment will be rendered.

## Persistence

The selected display mode persists across page reloads. You do not need to reset it each session.
